| 条件 | 計測値 |
|---|---|
| ClickMode の既定値 / IsPressed が読み取り専用か | Release / True |
| Hover（マウス）: ポインターが入る / 出る | Hover、IsPressed True / （なし）、IsPressed False |
| Press（マウス）: ボタンを押す / 離す | Press、IsPressed True / （なし）、IsPressed False |
| Release（マウス）: ボタンを押す / 離す | （なし）、IsPressed True / Release、IsPressed False |
| Release（マウス）: ボタンの上で押し、外へ動かして離す | 外へ動かした後の IsPressed False / （なし） |
| Release（キーボード）: Space を押す / Space を離す / Enter を押す | （なし）、IsPressed True / Release、IsPressed False / Release |
| Press（キーボード）: Space を押す / Space を離す / Enter を押す | Press、IsPressed True / （なし）、IsPressed False / Press |
| Hover（キーボード）: Space を押す / Space を離す / Enter を押す | （なし）、IsPressed False / （なし）、IsPressed False / （なし） |
