|  | Application.Exit | Run() が戻るか | プロセスが終わるまで |
|---|---|---|---|
| 表示したウィンドウだけ | 発生する | 戻る | 3.6 秒 |
| ウィンドウを 1 つも作らない | 発生しない | 戻らない | 終わらない |
| Window を作ったが閉じない | 発生しない | 戻らない | 終わらない |
| new Thread(\.\.\.) | 発生する | 戻る | 6.3 秒 |
| + IsBackground = true | 発生する | 戻る | 2.9 秒 |
| Task.Run(\.\.\.) | 発生する | 戻る | 3.2 秒 |
| 2 つ目の UI スレッド + Dispatcher.Run() | 発生する | 戻る | 終わらない |
| + Exit で InvokeShutdown() | 発生する | 戻る | 3.0 秒 |
