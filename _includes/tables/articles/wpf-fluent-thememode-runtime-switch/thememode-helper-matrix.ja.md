| ウィンドウの設定 | Window.ThemeMode | 切り替え前のブラシ | 切り替え後のブラシ | 追従するか |
|---|---|---|---|---|
| （指定なし） | None | \#E4000000 | \#FFFFFFFF | する |
| Window.ThemeMode=None | None | \#E4000000 | \#FFFFFFFF | する |
| Window.ThemeMode=Light | None | \#E4000000 | \#FFFFFFFF | する |
| Window.Resources に Fluent.Light.xaml | None | \#E4000000 | \#FFFFFFFF | する |
| App のリソースに Fluent.Light.xaml | None | \#E4000000 | \#FFFFFFFF | する |
| Styles.xaml の中に Fluent.Light.xaml | None | \#E4000000 | \#E4000000 | しない |
