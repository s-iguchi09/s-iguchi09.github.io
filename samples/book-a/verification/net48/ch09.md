# 第 9 章 付録サンプルと記事の実測の突き合わせ

環境: .NET Framework 4.8.9363.0（ランタイムは .NET Framework 4.8.1、Release 533509。ビルドの対象は .NETFramework,Version=v4.8） / Microsoft Windows 10.0.26200

記事: [WPF で StaticResource を変更しても画面が更新されない原因と解決方法](https://s-iguchi09.github.io/ja/articles/wpf-staticresource-vs-dynamicresource/)。記事の表は White（#FFFFFFFF）から Red（#FFFF0000）への差し替え、サンプルは SkyBlue（#FF87CEEB）から DarkSlateGray（#FF2F4F4F）への差し替えで、色の値は違う。比べているのは、差し替えの後も元の色のままか、差し替えた色になるか。「記事から期待する値」は、記事の実測の結果をサンプルの値（色・文言・データなど）で書き直したもの。記事の表の値そのものと違う場合は、「記事の該当箇所」に記事の値を書いている。

| 操作 | 記事の該当箇所 | 記事から期待する値 | サンプルの実測 | 期待と一致 |
|---|---|---|---|---|
| 再現版、「テーマを切り替える」の前と後 | 記事の表の StaticResource、差し替え前と差し替え後（記事の値は #FFFFFFFF → #FFFFFFFF。同じ値のまま） | 前 #FF87CEEB、後 #FF87CEEB | 前 #FF87CEEB、後 #FF87CEEB | 一致 |
| 修正版、「テーマを切り替える」の前と後 | 記事の表の DynamicResource、差し替え前と差し替え後（記事の値は #FFFFFFFF → #FFFF0000。差し替えた値になる） | 前 #FF87CEEB、後 #FF2F4F4F | 前 #FF87CEEB、後 #FF2F4F4F | 一致 |
