# 第 12 章 付録サンプルと記事の実測の突き合わせ

環境: .NET 10.0.10 / Microsoft Windows 10.0.26200

記事: [WPF でウィンドウを閉じてもプロセスが終了しない原因の切り分けと ShutdownMode・フォアグラウンドスレッドの扱い](https://s-iguchi09.github.io/ja/articles/wpf-application-not-exiting-shutdownmode-threads/)。子プロセスで、起動直後に監視（6 秒のスリープ）を始め、起動から 2 秒後にウィンドウを閉じた。起動から終了までが 6 秒以上なら「スリープが尽きるまで残る」、4 秒未満なら「閉じた直後に終わる」とした（記事の実測は 6.3 秒と 2.9 秒）。

| 操作 | 記事の該当箇所 | 記事の値 | サンプルの実測 | 記事と一致 |
|---|---|---|---|---|
| 再現版、監視を始めて 2 秒後にウィンドウを閉じる | new Thread(...) の行 | Exit 発生する、Run 戻る、プロセス: スリープが尽きるまで残る | Exit 発生する、Run 戻る、プロセス: スリープが尽きるまで残る | 一致 |
| 修正版、監視を始めて 2 秒後にウィンドウを閉じる | + IsBackground = true の行 | Exit 発生する、Run 戻る、プロセス: 閉じた直後に終わる | Exit 発生する、Run 戻る、プロセス: 閉じた直後に終わる | 一致 |
