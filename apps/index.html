Apps

Windows applications developed by s-iguchi. Each page includes feature descriptions, development background, UI/UX considerations, and links to the GitHub repository.

What Is Here

Everything on this page came out of building line-of-business WPF applications — either a problem that kept recurring until it was worth solving once, or infrastructure code that had been rewritten enough times to belong in a package. They fall into three groups:

  • Reference — applications for checking how a control or an API actually behaves, rather than reading what it is supposed to do. Useful during design and spec review.
  • Libraries — NuGet packages that remove boilerplate from application code.
  • Utilities — desktop tools for everyday work that is not specific to development.

All of them are open source under the MIT license, and the two that are applications rather than libraries ship pre-built executables, so no build environment is required to try them.

Reference

  • WPF Standard Control Demo App (.NET 10)

    A demo application covering the standard WPF controls on .NET 10. Each control can be configured interactively so you can see how its properties affect layout, styling, and behavior in a running application — including the pitfalls that only show up at runtime. Useful as a reference while deciding which control fits a screen, and as a way to check behavior on the current .NET release.

  • WPF MessageBox Sample Creator

    A prototyping tool for the standard MessageBox. Set the text, caption, button set, icon, default result and display options, then show the real dialog with those settings. Built for spec reviews: display the actual dialog to reviewers instead of describing it, and confirm wording, button order, and which button Enter activates before any code is written. A pre-built .exe is published on GitHub Releases.

Libraries

  • Xaml.ExtensionPack

    A lightweight, dependency-free XAML extension library for WPF, distributed as a NuGet package. Provides the MVVM foundations most applications end up writing by hand — BindableBase, RelayCommand, AsyncRelayCommand with built-in double-execution guarding, and a safe fire-and-forget helper. Multi-targets .NET 10, .NET 8, and .NET Framework 4.7.2, so the same view model code survives a migration to modern .NET.

Utilities

  • TreePaste

    A Windows tool that pastes copied files while preserving folder structure — and lets you choose how much of it to keep. Copied items appear as a tree, and the level you click becomes the root of the paste, so unwanted parent folders are dropped without deleting them afterwards. Stays in the system tray, opens with Ctrl+Alt+V, and reads the destination from the Explorer window in front of you.
