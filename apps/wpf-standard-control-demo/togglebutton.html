ToggleButton Inputs

ToggleButton is a button that stays pressed after a click and is released by the next one. CheckBox and RadioButton derive from it.

Overview

ToggleButton derives from ButtonBase, and both CheckBox and RadioButton derive from ToggleButton. Its state is IsChecked, a bool? that binds two-way by default. ToggleButton has no GroupName; for one-of-many choices, use RadioButton.

The default template has no visual state groups. It changes its look with a trigger on IsChecked = true only, so a button whose IsChecked is null looks the same as an unchecked one. If the undetermined state must be visible, the template has to show it. UI Automation does report all three states: ToggleState was Off, On, and Indeterminate for false, true, and null.

The demo app has two sections, IsChecked and IsThreeState, each showing the value next to the button. The "Show Code" link under each section displays its XAML.

Demonstrated Properties

The following properties are demonstrated interactively in the WPF Standard Control Demo App. The behavior described for each one was measured on .NET 10 (see Measured Behavior).

Property Values Description
IsChecked bool? (Null / False / True) Whether the button is pressed. The demo app shows three buttons starting at null, false, and true. None of them is three-state, so clicks alternate between false and true. The one that starts at null goes to false on the first click and cannot return to null.
IsThreeState bool Whether clicks include the undetermined state. With True, clicks went false → true → null → false; with the default False, false → true → false. Because the default template draws null like false, the demo app's three-state button looks unpressed in both states; the text next to it shows the difference.

ClickMode, Command, and Popup

These are not in the demo app's ToggleButton screen but are common with toggle buttons. They were measured in the same way.

  • ClickMode="Press" toggles when the mouse button goes down, and the new state stays after it is released: IsChecked was true after the button went down and still true after it came up. It does not make a button that is active only while held.
  • Command runs after the state has changed. With CommandParameter bound to the button's own IsChecked, a click from false passed True to Execute, and IsChecked was already true there. Toggling the button through UI Automation's Toggle, as an assistive technology does, changed IsChecked but did not run the command. Keep the state in a bound property if it must be handled for every way the button can be toggled.
  • A Popup whose IsOpen is bound to IsChecked opened when the button was clicked. When the popup closed, IsChecked returned to false, because Popup.IsOpen binds two-way by default.

XAML Example

The following XAML is the IsThreeState section of the demo app (ToggleButtonUsageControl.xaml), with the styles and the surrounding layout left out:

<ToggleButton x:Name="IsThreeStateTrueButton" HorizontalAlignment="Stretch"
              Content="ToggleButton" IsThreeState="True" />
<TextBlock HorizontalAlignment="Center"
           Text="{Binding IsChecked, ElementName=IsThreeStateTrueButton, TargetNullValue=(Null)}" />

<ToggleButton x:Name="IsThreeStateFalseButton" HorizontalAlignment="Stretch"
              Content="ToggleButton" IsThreeState="False" />
<TextBlock HorizontalAlignment="Center"
           Text="{Binding IsChecked, ElementName=IsThreeStateFalseButton}" />

Common Use Cases

  • Toolbar toggles: bold, italic, or a drawing mode that stays on until turned off.
  • Showing panels and popups: a button whose IsChecked drives a panel's visibility or a popup's IsOpen.
  • Custom switches: a ToggleButton with its own template drawn as an on/off switch.

Tips and Best Practices

  • Give the template a look for null if you use IsThreeState; the default template does not have one.
  • Pass the new state with a binding. CommandParameter="{Binding IsChecked, RelativeSource={RelativeSource Self}}" delivers the state after the click.
  • Do not rely on Command alone. A toggle through UI Automation changes IsChecked without running the command.
  • Use RadioButton for mutually exclusive toggles. ToggleButton has no GroupName.

Measured Behavior

Every behavior on this page was measured by running it on .NET 10 / Windows 11, using ToggleButtonDemoScene in this site's screenshot tool. State changes were made with UI Automation's Toggle. The command was run through the button's click handling (OnClick), and ClickMode was checked by raising the left-button events.
