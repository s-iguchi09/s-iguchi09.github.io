WPF Standard Control Demo App (.NET 10)

A Windows app that shows 36 WPF standard controls on .NET 10. Each control has its own page, with inputs that change its properties and a "Show Code" link that shows the XAML behind each section.

What the App Shows

The window lists the controls on the left in nine groups: Inputs, Layout, Display, List, Graphics, Selectors, Menu, Overlays, and Resizer. Selecting one opens its page. A page is split into sections, one for each property or feature. Each section puts input controls, such as a ComboBox of enum values, a Slider, or a CheckBox, next to the control being demonstrated, so the effect of a value shows as soon as it is changed.

"Show Code" under a section opens a popup with the XAML of the elements in that section. The text is not a separate copy that could drift from the app: the build embeds each page's XAML source in the executable, and the popup picks out the section's elements by x:Name at run time. What it shows is the markup that is running.

Styles

The controls being demonstrated keep the look of WPF's default styles. The app does not set ThemeMode, so they appear in the classic theme rather than Fluent. The app's own styles, in nine ResourceDictionary files merged in App.xaml, all have an x:Key. They style only the app's frame, such as the list of controls, the group boxes around sections, the sliders used as inputs, the "Show Code" link, and the code popup. Because none of them is an implicit style, they do not change the controls on the pages.

A few pages add local styles of their own, for example to set the spacing of the check boxes on the DataGrid page or to demonstrate RowStyle and CellStyle. They are part of that page's XAML in the repository.

Downloads and Requirements

GitHub Releases has two ZIP files for each version, both for 64-bit Windows:

  • standalone: a self-contained single-file executable (about 59 MB). It includes the .NET runtime, so nothing else needs to be installed.
  • without "standalone": a framework-dependent single-file executable (about 250 KB). It needs the .NET 10 Desktop Runtime.

The source targets net10.0-windows and opens as a .slnx solution in Visual Studio 2026.

Detailed documentation for each control demonstrated in the app is available on the pages below. Each page covers the control's overview and an explanation of each property and its behavior. The behavior on every page was measured by running it on .NET 10 / Windows 11, and each page links to the code that measured it.
