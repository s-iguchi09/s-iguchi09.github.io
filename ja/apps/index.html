アプリ一覧

s-iguchi が開発した Windows アプリケーションの一覧です。 各ページでは、機能の説明、開発の背景、UI/UX 上の検討内容、GitHub リポジトリへのリンクを掲載しています。

公開しているもの

ここで公開しているものは、いずれも業務系の WPF アプリケーションを開発する中で生まれました。 繰り返し遭遇して一度きちんと解決する価値が出た課題か、 何度も書き直したためパッケージにまとめるべきだと判断した基盤コードのどちらかです。 内容は次の 3 つに分かれます。

  • リファレンス —— コントロールや API の仕様を読むのではなく、実際の挙動を確認するためのアプリケーションです。 設計時や仕様レビューの場面で使えます。
  • ライブラリ —— アプリケーション側のコードから定型処理を取り除く、再利用可能なパッケージです。
  • ユーティリティ —— 開発に限らない、日常の作業向けのデスクトップツールです。

すべて MIT ライセンスのオープンソースとして公開しています。 ライブラリを除く 3 つのアプリケーション（コントロールデモ、MessageBox ツール、TreePaste）は GitHub Releases でビルド済みの実行ファイルも配布しているため、ビルド環境がなくても試せます。

リファレンス

  • WPF 標準コントロールデモアプリ (.NET 10)

    .NET 10 上で WPF の標準コントロールを一通り確認できるデモアプリケーションです。 各コントロールをその場で設定しながら、プロパティがレイアウト・スタイル・挙動にどう影響するかを、 実行中のアプリケーションで確認できます。実行時にしか現れない落とし穴も含めて確認できるため、 画面にどのコントロールを使うか判断するときの参照先として、また最新の .NET での挙動確認用として使えます。

  • WPF MessageBoxサンプル作成ツール

    標準の MessageBox 向けのプロトタイピングツールです。 本文・タイトル・ボタン構成・アイコン・既定の結果・表示オプションを設定し、その設定のまま実物のダイアログを表示できます。 仕様レビューでの利用を想定しており、口頭で説明する代わりに実物を見せて、 文言・ボタンの並び・Enter キーで押されるボタンを、コードを書く前に確定できます。 ビルド済みの .exe を GitHub Releases で公開しています。

ライブラリ

  • Xaml.ExtensionPack

    WPF 向けの軽量・依存関係なしの XAML 拡張ライブラリで、プロジェクト参照として利用します。 多くのアプリケーションで自前実装することになる MVVM の土台 —— BindableBase、RelayCommand、二重実行の防止を内蔵した AsyncRelayCommand、 安全な fire-and-forget ヘルパー —— を提供します。 .NET 10 / .NET 8 / .NET Framework 4.7.2 をマルチターゲットしているため、 モダン .NET への移行をまたいでも同じ ViewModel のコードを使い続けられます。

ユーティリティ

  • TreePaste

    コピーしたファイルをフォルダー構成を保ったまま貼り付けられる Windows ツールです。 どの階層から残すかを選べる点が特徴で、コピーした項目がツリーとして表示され、 クリックした階層が貼り付けの起点になります。不要な親フォルダーは、後から削除するのではなく最初から作られません。 タスクトレイに常駐し、Ctrl+Alt+V で呼び出せます。貼り付け先は目の前のエクスプローラーから読み取ります。
