WPF 標準コントロールデモアプリ (.NET 10)

.NET 10 で動く WPF の標準コントロール 36 種を確認できる Windows アプリです。コントロールごとにページがあり、プロパティを変える入力欄と、各節の XAML を表示する「Show Code」を備えています。

アプリの内容

ウィンドウの左に、コントロールが Inputs・Layout・Display・List・Graphics・Selectors・Menu・Overlays・Resizer の 9 つのグループに分けて並びます。選ぶとそのページが開きます。ページはプロパティや機能ごとの節に分かれ、各節では、列挙値の ComboBox・Slider・CheckBox などの入力欄が、デモ対象のコントロールの隣に置かれています。値を変えると、その効果がすぐに表示されます。

節の下の「Show Code」を押すと、その節の要素の XAML がポップアップに表示されます。この文字列は、アプリとずれうる別の写しではありません。ビルド時に各ページの XAML のソースを実行ファイルに埋め込み、実行時に節の要素を x:Name で抜き出しています。表示されるのは、実際に動いているマークアップです。

スタイル

デモ対象のコントロールは、後述の 1 つの例外を除き、WPF の既定のスタイルのままの見た目です。アプリは ThemeMode を設定していないため、Fluent ではなく、WPF の既定の Aero2 テーマで表示されます。アプリ共通のスタイルは、App.xaml でマージする 9 つの ResourceDictionary にあり、すべて x:Key を持つため、参照した要素にだけ適用されます。参照しているのは、コントロールの一覧、節を囲む GroupBox と Expander、入力欄の Slider、「Show Code」のリンク、コードのポップアップなど、アプリの枠組みだけで、デモ対象のコントロールは参照していません。暗黙のスタイルも 1 つも無いため、デモ対象のコントロールには届きません。

いくつかのページは、独自のスタイルを持ちます。多くは入力欄を整えるものか、プロパティを示すためのもので、たとえば DataGrid のページの CheckBox の余白や、RowStyle と CellStyle の見本です。例外は DatePicker のページで、そこでは暗黙のスタイルが、デモ対象を含むページ内のすべての DatePicker について、カレンダーボタン（PART_Button）の縦位置と余白を設定しています。これらのスタイルは、リポジトリの各ページの XAML にあります。

ダウンロードと動作環境

GitHub Releases の最新版 v1.0.0.0 には、2 つの ZIP があります（それ以前のリリースは ZIP が 1 つです）。どちらも 64 ビット版 Windows 用です。

  • standalone 付き: 自己完結型の単一ファイルの実行ファイル（約 59 MB）です。.NET のランタイムを含むため、ほかに何もインストールする必要はありません。
  • standalone なし: フレームワーク依存の単一ファイルの実行ファイル（約 250 KB）です。.NET 10 デスクトップ ランタイムが必要です。

ソースは net10.0-windows を対象とし、Visual Studio 2026 で .slnx のソリューションとして開きます。

コントロール別解説ページ

アプリでデモしている各コントロールの詳細解説ページを以下に用意しています。 各ページでは、コントロールの概要と、デモしているプロパティの解説・設定値ごとの動作を説明します。 どのページの挙動も .NET 10 / Windows 11 で実際に動かして確かめたもので、各ページから計測したコードへリンクしています。

Inputs（入力系）

  • TextBox

    テキスト入力、折り返し、文字種変換、最大文字数など。

  • PasswordBox

    パスワードマスク文字、キャレット色、選択色、最大文字数。

  • Button

    IsCancel、IsDefault、ClickMode、Command、CommandParameter。

  • RepeatButton

    Delay と Interval による連続クリック発火の制御。

  • ToggleButton

    IsChecked の 3 状態（Null/False/True）、IsThreeState。

  • CheckBox

    IsChecked、IsThreeState、VerticalContentAlignment。

  • RadioButton

    GroupName による排他制御、VerticalContentAlignment。

  • ComboBox

    IsEditable、IsReadOnly、SelectedValue、DisplayMemberPath など。

  • DatePicker

    SelectedDate、DisplayDate の範囲、FirstDayOfWeek、SelectedDateFormat。

  • Slider

    値の範囲、向き、目盛り、オートツールチップなど。

Layout（レイアウト系）

  • Grid

    行・列の配置、スパン、SharedSizeGroup、サイズルール。

  • StackPanel

    Orientation、背景色、Z 順。

  • WrapPanel

    Orientation、ItemHeight、ItemWidth。

  • DockPanel

    Dock 添付プロパティ、LastChildFill。

  • UniformGrid

    Columns、Rows、FirstColumn による均等グリッドレイアウト。

  • Viewbox

    Stretch と StretchDirection によるコンテンツのスケーリング。

  • ScrollViewer

    スクロールバー表示設定、遅延スクロール、スクロール状態プロパティ。

Display（表示系）

  • TextBlock

    テキスト、折り返し、省略、フォントプロパティ、文字色、行高。

  • Label

    Target（アクセスキー）、コンテンツ、フォントプロパティ、ボーダー。

  • ProgressBar

    IsIndeterminate モード、Orientation。

  • GroupBox

    ヘッダー、コンテンツ、パディング、フォントプロパティ、ボーダー。

  • Expander

    IsExpanded、ExpandDirection、ヘッダー、コンテンツ、フォントプロパティ。

List（リスト系）

  • ListBox

    SelectionMode、DisplayMemberPath、SelectedValue、スクロールバー。

  • ListView

    GridView 列設定、AllowsColumnReorder、SelectionMode。

  • TreeView

    IsExpanded、IsSelected、HierarchicalDataTemplate。

  • DataGrid

    AutoGenerateColumns、SelectionMode、編集機能など豊富なプロパティ。

Graphics（グラフィック系）

  • Image

    Source、Stretch、StretchDirection。

  • Canvas

    Top/Left/Right/Bottom による絶対座標配置、ZIndex。

  • InkCanvas

    EditingMode、描画属性、ストローク。

Selectors（セレクター系）

  • TabControl

    TabStripPlacement、SelectedContent。

  • TabItem

    IsSelected、TabStripPlacement。

Menu（メニュー系）

  • Menu

    IsMainMenu、MenuItem のプロパティ：IsCheckable、Command、Icon など。

  • ToolBar

    オーバーフローアイテム、Band/BandIndex、ToolBarTray の方向。

Overlays（オーバーレイ系）

  • ToolTip

    Placement、タイミング（ToolTipService）、外観のカスタマイズ。

  • Popup

    IsOpen、StaysOpen、Placement、PopupAnimation。

Resizer（リサイザー系）

  • GridSplitter

    ResizeDirection、ResizeBehavior、ShowsPreview、DragIncrement。
